# PINK NOISE CLUB

Website katalog kopi dan makanan yang dibuat untuk tugas Pemrograman Web menggunakan Node.js, Express.js, dan EJS.

## Fitur
- Menampilkan katalog kopi dan makanan.
- Filter menu berdasarkan kategori menggunakan `req.query`.
- Menampilkan detail menu menggunakan `req.params`.
- Menggunakan partial navbar dan footer dengan EJS.
- Menampilkan halaman 404 jika menu tidak ditemukan.

## Teknologi
- Node.js
- Express.js
- EJS
- HTML dan CSS

## Cara Menjalankan
1. Buka terminal pada folder proyek.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.
4. Buka `http://localhost:3000/menu` di browser.
